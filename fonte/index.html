por que uma fonte

Quem não tem dono também não devia alugar a própria letra.

O coletivo nasceu de uma ideia simples: quem trabalha fica com o que é seu. Só que a marca vinha vestida com Futura — uma fonte licenciada, que a gente pediria emprestada para sempre, e que cai em qualquer substituta que o aparelho tiver na hora.

A Coletivo Sans resolve as duas coisas. É desenho próprio, desenhado para as telas do coletivo: cardápio, preço, botão, painel de cozinha. E é livre — qualquer restaurante, entregador ou pessoa da mesa pode baixar, usar e modificar.

a voz

Geometria de mesa: redondo com o canto reto.

Os redondos não são círculos puros, como na Futura, nem elipses moles. São superelipses — a curva fica cheia perto da diagonal e quase reta nos lados, como um tampo de mesa redonda com a borda viva. Isso deixa mais ar dentro da letra, o que segura o desenho no tamanho pequeno da lista de pedidos, e dá à família uma voz que não é de ninguém mais.

A altura-x é alta para uma geométrica (512 de 1000), a caixa alta é contida, e a família inteira é mais estreita que as vizinhas de referência: cabe mais linha na tela sem apertar a leitura.

em texto corrido

A prova é o parágrafo, não a palavra.

O coletivo tira o intermediário caro do meio. O restaurante fica com o que é dele; o entregador ganha o que vale a corrida; você paga o justo. Não é um dono mais barato — é não ter dono. Cada pedido mostra quanto foi para a cozinha, quanto foi para quem pedalou e quanto ficou para manter o aplicativo de pé.

como usar

Uma linha de CSS. 37 KB para os seis pesos.

/* a variável cobre 300–900 num arquivo só */
<link rel="stylesheet" href="https://coletivo.app/fonte/coletivo-sans.css">

body {
  font-family: var(--fonte-coletivo);
  /* = 'Coletivo Sans', Futura, 'Century Gothic', Jost, sans-serif */
}
h1 { font-weight: 500; }        /* qualquer valor de 300 a 900 vale */
.preco { font-variant-numeric: tabular-nums; }  /* já é o padrão */

Os algarismos são tabulares de fábrica: preço em coluna alinha sozinho, sem ajuste.
